dustyMenu Package Service

Signed emulator installation is available in dustyMenu under Settings → Install Emulators.

Packages include GBARunner3, GBARunner2, GameYob, nesDS, SNEmulDS 0.6a/0.6d, and PicoDriveTWL. Game and save compatibility on DS Lite remains under qualification.

jEnesisDS is local-only and is never hosted here. No game ROMs or proprietary BIOS files are distributed.
